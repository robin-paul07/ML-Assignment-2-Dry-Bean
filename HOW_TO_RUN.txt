1. Extract this project folder in BITS Virtual Lab.
2. Open a terminal in the project folder.
3. Run: pip install -r requirements.txt
4. Run: python train_models.py
5. Confirm that model/*.joblib, test_data.csv, metrics_summary.csv and model_metadata.json were created.
6. Run: streamlit run app.py
7. Upload test_data.csv and test all five models.
8. Copy actual metrics into README.md and write evidence-based observations.
9. Push all required files to your own GitHub repository.
10. Deploy app.py using Streamlit Community Cloud.
11. Capture the BITS Virtual Lab screenshot and prepare the final single PDF.
